# 文档总索引

本目录只允许五个位置：`README.md`、`架构全景图.md`、`需求/`、`流程/`、`功能/`。

## 目录约定

| 位置 | 内容 | 命名 |
|---|---|---|
| `README.md` | 总索引与目录约定 | 固定 |
| `架构全景图.md` | 系统上下文、部署拓扑、运行时链路 | 固定 |
| `需求/{四位编号}/` | 一个需求一个目录，含五件套、`assets/`、`sql/` | `{编号}-{中文名称}-{文档类型}.md` |
| `流程/` | 按功能点拆分的流程图、时序图、状态机 | `{两位编号}-{中文名称}-v{N}.md` |
| `功能/` | 架构、功能清单、术语、限制、规范、选型 | `{两位编号}-{中文名称}.md` |

文档类型固定五种：需求清单、方案评估、实施方案、方案验收、前端对接文档。
