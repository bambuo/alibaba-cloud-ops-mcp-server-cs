## 三、范围

### 纳入

1. 以 C# 重写上游 MCP 服务，保持工具面、参数 schema、CLI 参数与凭证优先级一致。
2. 保留 40 个默认工具、`--services` 追加的 4 个通用工具、`--code-deploy` 模式与 `--visible-tools` 白名单。
3. 保留动态 API 工具能力，包括 `--extra-config` 追加服务与 API。
4. 保留本地工具（列目录、执行脚本、技术栈识别）与 CodeDeploy 部署链路。
5. 建立文档体系：README、AGENTS.md、架构全景图、功能文档、流程文档、需求五件套。

### 不纳入

1. 新增业务能力或新增云产品工具。
2. 修改上游工具描述、提示词与参数名。
3. Web 前端、管理后台、数据库。
4. 生产部署、CI/CD 流水线、包发布。
5. 本轮的 C# 代码实现与真账号联调。
