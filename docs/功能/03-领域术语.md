# 03 领域术语

> 文档编号：03
> 状态：已实现，术语与代码映射一致
> 证据基线：上游 v0.9.27

## 使用规则

- 文档、提交信息、代码注释统一使用「主术语」。
- 代码标识符保留英文原名，不为了统一术语做批量重命名。
- 上游工具名与参数名是模型可见契约，**不翻译、不改写**。

## 核心术语

| 主术语 | 英文 / 代码映射 | 定义 | 允许别名 | 避免用法 |
|---|---|---|---|---|
| MCP 服务 | MCP Server | 通过 Model Context Protocol 向客户端暴露工具与资源的进程 | 服务端 | 「后端」「接口服务」 |
| 工具 | Tool / `McpServerTool` | 客户端可发现并调用的一个能力，含名称、描述、输入 schema | 能力 | 「接口」「方法」「函数」 |
| 静态工具 | static tool | 编译期定义、启动即注册的工具 | 固定工具 | 「内置接口」 |
| 动态 API 工具 | dynamic API tool | 启动时按 OpenAPI 元数据生成 schema 并注册的工具 | 动态工具 | 「自动接口」 |
| 泛化调用 | generic call / `CallApi` | 用 Action、Version、Style、Path 等元数据直接调用 OpenAPI，不依赖产品 SDK | 通用调用 | 「裸调用」「HTTP 调用」 |
| 产品 SDK | product SDK | 按云产品生成的强类型 SDK，如 `AlibabaCloud.SDK.Oos20190601` | 强类型 SDK | 「官方包」 |
| API 元数据 | API Meta | `api.aliyun.com/meta/v1` 返回的 API 版本、参数、风格、路径等描述 | 元数据 | 「接口文档」 |
| 服务码 | service code | 元数据与工具名前缀使用的产品标识，如 `ecs`、`r-kvstore` | 服务名 | 「产品 ID」 |
| 端点 | endpoint | 某个服务在某个地域的访问域名 | 访问地址 | 「域名」「URL」（URL 含路径，端点不含） |
| 地域 | region / `RegionId` | 阿里云资源部署的地理区域，如 `cn-hangzhou` | 区域 | 「机房」「可用区」 |
| 可用区 | zone / `ZoneId` | 地域内的独立故障域 | AZ | 「区域」 |
| 凭证 | credential | 调用阿里云所需的 AK/SK 或 STS 临时凭证 | 凭据 | 「密钥」（密钥仅指 SK） |
| 凭证链 | credential chain | 环境变量、配置文件、RAM 角色、实例元数据依次尝试的凭证来源 | 默认凭证链 | 「凭证池」 |
| STS 令牌 | security token | 临时凭证附带的会话令牌 | 临时令牌 | 「Token」（与 MCP 无关，避免混用） |
| OOS | Operations Orchestration Service | 运维编排服务，本服务用它执行批量运维与部署 | 运维编排 | 「任务系统」 |
| 模板 | template / `TemplateName` | OOS 预置的编排定义，如 `ACS-ECS-BulkyStopInstances` | 公共模板 | 「脚本」 |
| 执行 | execution / `ExecutionId` | 一次模板运行实例 | 执行记录 | 「任务」「作业」 |
| 应用 | application | OOS CodeDeploy 中承载部署逻辑的逻辑单元 | 部署应用 | 「项目」「服务」 |
| 应用分组 | application group | 应用下绑定一组 ECS 实例的部署单元 | 分组 | 「集群」 |
| 部署 | deployment | 把产物发布到应用分组并执行启停命令的过程 | 发布 | 「上线」（口语，文档不用） |
| 产物 | artifact / release | 构建后用于部署的压缩包或可执行文件 | 部署包 | 「构建物」 |
| 资源打标 | tagging / `TagResources` | 给 ECS 实例打标签，使其归属到应用分组 | 打标签 | 「标记」 |
| 技术栈识别 | deploy stack analysis | 通过配置文件判断语言、包管理器与启动方式 | 栈识别 | 「环境检测」 |
| 可见工具白名单 | visible tools | `--visible-tools` 指定的允许注册的工具集合 | 白名单 | 「工具过滤」（过滤是动作，不是配置名） |
| 传输 | transport | MCP 的通信方式，支持 stdio 与 streamable-http | 通道 | 「协议」（协议是 MCP 本身） |
| 无状态模式 | stateless HTTP | HTTP 传输不为每个客户端保留会话状态 | 无状态传输 | 「无 Session」 |
| 实例 | instance / `InstanceId` | 一台 ECS 或 RDS 实例 | 云主机（仅 ECS 口语） | 「节点」「机器」 |
| 指标 | metric / `MetricName` | CMS 采集的监控项，如 `cpu_total` | 监控项 | 「数据」 |
| 维度 | dimension | 指标的过滤键值，如 `instanceId` | 标签（与资源标签冲突，避免） | 「分组」 |
| 存储空间 | bucket | OSS 的顶层容器 | Bucket | 「目录」「文件夹」 |
| 对象 | object / `ObjectKey` | OSS 中的文件条目 | 文件 | 「路径」 |

## 易混术语对照

| A | B | 区别 |
|---|---|---|
| 工具（Tool） | API | 工具是 MCP 暴露的能力，一个工具通常对应一个 API；动态工具名 = 服务码 + `_` + API 名 |
| `OOS_RunCommand` | `OOS_RunInstances` | 前者在已有实例上执行命令，后者创建新实例 |
| 部署（deployment） | 执行（execution） | 部署是业务动作，底层由一次或多次 OOS 执行完成 |
| 实例（instance） | 应用（application） | 实例是计算资源，应用是部署逻辑单元；应用分组才与实例绑定 |
| `--env` | 环境变量 | `--env` 只切换国内/国际端点；环境变量用于凭证与运行配置 |
| 端点（endpoint） | API 路径（pathname） | 端点决定访问哪个域名，pathname 决定 ROA 风格 API 的资源路径 |
| 只读工具 | 只读 API | 工具是否只读由行为决定，不能仅凭 API 名含 `Describe` 判断全部副作用 |
| 产物（artifact） | 对象（object） | 产物是本地构建结果，上传后成为 OSS 对象 |

## 状态口径

| 场景 | 上游口径 | C# 文档口径 |
|---|---|---|
| 工具可用 | 已注册并在 `tools/list` 中返回 | 「上游有效」 |
| 代码未实现 | 不适用 | 「C# 待实现」 |
| 已声明行为差异 | 无 | 「已声明差异」，必须写进实施方案例外清单 |
| 缺陷但保留 | 无标注 | 「保留兼容」，注明原因 |
| 未验证结论 | 无标注 | 「待确认」，不得写成事实 |
