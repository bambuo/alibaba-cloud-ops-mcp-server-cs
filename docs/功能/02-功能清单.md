# 02 功能清单

> 文档编号：02
> 状态：C# 已实现，本机工具面对账通过
> 证据基线：上游 v0.9.27，commit 751a8fd（2026-10-27）

## 统计口径

- 分母来源：上游 `src/alibaba_cloud_ops_mcp_server/tools/*.py` 中带 `@tools.append` 或被 `mcp.tool()` 注册的函数，加上 `config.py` 驱动的动态 API 工具。
- 注册规则：普通模式跳过静态 `ECS_DescribeInstances`，由动态工具提供同名能力，避免重复。
- 不计入：未注册的 `OSS_PutObject`、内部辅助函数、`_append_tool` 等。
- 复核命令（在上游仓库执行）：

```bash
grep -rn "@tools.append" src/alibaba_cloud_ops_mcp_server/tools/
grep -n "def OSS_PutObject" src/alibaba_cloud_ops_mcp_server/tools/oss_tools.py
```

## OSS 工具（4）

使用 OSS SDK 独立签名，鉴权 AK/SK。返回值在上游是 Python SDK 对象字符串，C# 版必须改为结构化 JSON，属已声明差异。

| 工具 | 功能 | 破坏性 |
|---|---|---|
| `OSS_ListBuckets` | 列出 Bucket | 否 |
| `OSS_ListObjects` | 列出对象 | 否 |
| `OSS_PutBucket` | 创建 Bucket | 是 |
| `OSS_DeleteBucket` | 删除 Bucket | 是 |

`OSS_PutObject` 在 `oss_tools.py` 中存在但**没有注册装饰器**，不作为工具暴露；C# 版是否补齐需在实施方案确认。

## 重复、未启用与特殊项

| 项 | 说明 | 处理建议 |
|---|---|---|
| `ECS_DescribeInstances` 双实现 | 动态工具与 `application_management_tools.py` 各有一份 | 普通模式保留动态版本，`--code-deploy` 使用静态版本 |
| `OSS_PutObject` 未注册 | 无 `@tools.append` | 保持不注册以对齐；如需暴露单独评审 |
| 9 个 CMS 工具 | 同一函数不同 metric 参数 | 可用表驱动实现，工具名保持不变 |
| `--code-deploy` 数量不一致 | `README_mcp_args_zh.md` 写 6 个，代码实际注册 7 个 | 以代码为准，文档标注差异 |
| `ForeceStop` 拼写 | `OOS_StopInstances` / `OOS_RebootInstances` 参数名 | 保持原样以兼容模型已形成的调用习惯 |
