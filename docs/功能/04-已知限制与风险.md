# 04 已知限制与风险

> 文档编号：04
> 状态：已实现，限制与风险按实测更新
> 证据基线：上游 v0.9.27

## 一、当前阶段限制

| 限制 | 影响 | 解除条件 |
|---|---|---|
| 仓库无代码 | 无法构建、无法联调、无法真账号验证 | 实施阶段落地 |
| 未初始化 git | 无提交历史、无基线 diff | 用户确认后 `git init` |

## 二、已声明的行为差异

这些差异是重写导致的，不是缺陷；实现与验收都以本表为准。

| 差异 | 上游 | C# 规划 | 原因 |
|---|---|---|---|
| OSS 工具返回值 | `str(result)`，Python 对象 repr | 结构化 JSON | 无法等价复刻 Python repr，且 JSON 对模型更稳定 |
| CMS 返回值 | SDK datapoints 对象 | JSON 数组 | 同上 |
| SSE 传输 | 支持 `--transport sse` | 首版不支持 | MCP 规范已由 Streamable HTTP 取代 |
| `--extra-config` 格式 | JSON 或 Python 单引号字典 | 仅 JSON | 无 `ast.literal_eval` 等价物 |
| 动态工具 schema 生成 | `inspect.Signature` + pydantic | 手写 JSON Schema | C# 无运行时签名注入 |
| 轮询超时 | 无总超时 | 可配置总超时 | 防止无限等待 |
| 元数据请求次数 | 每次调用重复拉取 | 进程内缓存 | 降低启动与调用延迟 |
| 工具注解 | 无显式注解 | 标注只读/破坏性/幂等 | 改善客户端确认体验，需评审 |

## 三、技术风险

| 风险 | 概率 | 影响 | 缓解措施 | 触发信号 |
|---|---|---|---|---|
| 动态工具在 `ModelContextProtocol` 2.4.0 上无法自定义 `InputSchema` | 中 | 高 | 先做 0.5–1 天技术验证；失败降级为 11 个手写静态工具 | `tools/list` 返回的 schema 缺少业务参数 |
| `AlibabaCloud.OSS.V2` 0.3.0 API 不稳定 | 中 | 中 | `IArtifactStore` 抽象，备选 `Aliyun.OSS.SDK.NetCore` 2.14.1 | 编译失败或上传行为不符 |
| 部署规则引擎移植漂移 | 中 | 高 | 先移植 435 行规则测试，再写实现；可用 fixture 双跑对账 | 同一输入生成的启动命令不同 |
| HTTP 传输下取不到请求头凭证 | 中 | 中 | 技术验证；失败则仅支持环境变量模式并文档说明 | `IHttpContextAccessor` 为空 |
| 长轮询阻塞或无法取消 | 中 | 中 | 注入 `TimeProvider`，全链路 `CancellationToken` | 客户端取消后进程仍轮询 |
| stdio 模式日志污染 stdout | 低 | 高 | 日志只写 stderr，加集成测试断言 | 客户端解析协议失败 |
| Windows 下 shell 语义不一致 | 高 | 低 | 首版只保证 Linux/macOS，Windows 标为待验证 | `LOCAL_RunShellScript` 行为差异 |
| 上游缺陷被原样固化 | 高 | 中 | 例外清单逐项确认，不默认修正 | 代码评审提出拼写/数量问题 |

## 四、兼容性风险

| 项 | 风险 | 处理 |
|---|---|---|
| 工具描述与 instructions | 翻译或改写会改变模型行为 | 原文保留，禁止润色 |
| 参数名 `ForeceStop` | 改名会破坏已有提示词与调用习惯 | 默认保留，待确认 |
| `--code-deploy` 工具数 6 vs 7 | 以文档为准会少注册工具 | 以代码为准，文档标注差异 |
| 动态工具 schema 的 required/default | 不一致会导致模型漏传参数 | 以元数据 `required` 为准，`RegionId` 默认 `cn-hangzhou` |
| 错误消息格式 | 客户端可能按文本匹配 | 统一 `isError: true` + 稳定错误前缀 |

## 五、安全风险

| 项 | 说明 | 建议 |
|---|---|---|
| `LOCAL_RunShellScript` | 任意命令执行 | 最小权限运行；可选根目录限制；不在公网暴露 stdio 包装服务 |
| 破坏性工具 | 删除实例/Bucket、重置密码、换盘、批量执行命令 | 默认全部注册；用 `--visible-tools` 收敛；客户端侧开启确认 |
| 请求头凭证 | HTTP 模式下凭证随请求传输 | 仅内网或 TLS 终止后使用；日志不得记录请求头 |
| 端点覆盖 | `--env international` 会切换域名 | 与账号站点不匹配时调用失败，需在文档提示 |
| 元数据接口 | 启动时访问外网 | 离线环境需允许跳过或预置元数据 |
